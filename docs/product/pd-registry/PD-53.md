Owner decision, 2026-10-31 (the owner explicitly approved reopening the frozen voice-call code
for this scope only). The requirements, verbatim:

1. If a call drops unexpectedly, wait 60 seconds before automatically ending it.
2. Allow either participant to reconnect within this 60-second grace period and resume the same call.
3. If reconnection does not happen within 60 seconds, automatically terminate the call.
4. Notify the other participant that the call ended due to a connection interruption.
5. Record the actual connected call duration, excluding the disconnection period.
6. Distinguish unexpected network disconnections from intentional call termination.

Consistent across teacher and parent accounts and the staff side (Admin Web calls). Group calls
keep the owner's rule that one decline ends a ringing group call; one member's drop with two
still connected does not interrupt the call (the member is out after the grace). Design approved
by the department head, 2026-10-31. Number assigned by the department head.
