# Handoff supporting files

`/HANDOFF.md` is the full handoff. `docs/handoff/whatsapp/part-NN.txt` is the same text cut into WhatsApp-sized parts (about 6,000 characters each, split at paragraph boundaries; tables stay as pipe text).
On the Mac: `pbcopy < docs/handoff/whatsapp/part-01.txt`, then paste, and repeat for each part in order.
Regenerate after editing HANDOFF.md by re-running the split described in the session (it is a 15-line script; ask Claude).
