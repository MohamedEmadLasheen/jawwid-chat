# Jawwid Chat — Failure Scenario Matrix

**Owner:** AI #8 · **Date:** 2026-09-05
**Method:** each scenario was traced against code, not documentation. "Current behaviour"
describes the repository as it stands (working tree + all four branches). Where nothing is
implemented, that is stated as the behaviour, because *unbuilt* and *broken* have the same
operational consequence on launch day.

Severity: **P0** severe operational failure / MVP unusable · **P1** significant, fix before
pilot · **P2** important, workaround exists · **P3** optimisation.
